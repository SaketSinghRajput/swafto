# Design reference renders

The 40 screens of `SWAFTO daily closing app design/Phone.dc.html` (the Claude
Design artifact), rendered by `render-reference.mjs` in headless Chromium at
393 x 876 CSS px, deviceScaleFactor 2 - the same logical size as the test
handset (iQOO I2219). `comfort/index.json` maps each screen id to its name.

These are the visual source of truth for every screen they contain. Build
from the picture, not from a prose description of it.
